# Project Context for IBM Bob

## Purpose
Educational ML project for the AICTE | IBM SkillsBuild Machine Learning & Applied AI internship.

## Application
Student Success Predictor & Early-Warning Dashboard.

## Stack
Python, pandas, NumPy, scikit-learn, joblib, Streamlit, matplotlib, pytest.

## Commands
python src/generate_data.py
python src/train_model.py
streamlit run app.py
pytest -q

## Rules
- Data is synthetic/demo data only.
- Never claim the model is validated for real academic decisions.
- Keep the application runnable locally.
- Prefer simple, readable Python.
- Add/update tests when behavior changes.
- Avoid unnecessary dependencies.
- Never include secrets or personal student data.
- Use Plan mode for substantial changes, Agent mode for implementation, Ask mode for explanations.
